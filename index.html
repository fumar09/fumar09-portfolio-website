Featured project

Civic platform / service UX

E-Barangay ni Kap

A barangay-focused digital platform designed to make local services, requests, and community information easier to access and manage. It is the clearest example of how I approach civic workflows with more structure, clarity, and trust.

What this project highlights

Service flow planning, interface hierarchy, responsive layout, and frontend decisions that make public-facing tasks feel simpler and more trustworthy.

  • Civic tech
  • Service flows
  • Responsive UI
  • Information clarity

Challenge

Barangay processes can easily feel manual, fragmented, and intimidating when steps are unclear or information is scattered across screens and announcements.

Approach

The approach centers on clearer navigation, simpler request pathways, and stronger hierarchy so residents can understand what to do, what is needed, and what happens next.

System thinking

Reusable sections, consistent form patterns, and cleaner page rhythm help the platform feel dependable across services, records, and community updates.

Outcome

The result is a civic service experience that feels clearer, more organized, and more trustworthy for residents using digital barangay tools.

Core objective Simplify local access

Make digital barangay services feel more approachable, guided, and easier to complete on any screen size.

Experience focus Requests, records, updates

The interface is organized around the tasks residents need most, with clearer navigation and easier access to key information.

Design value Trust through clarity

Consistent forms, cleaner structure, and more readable screens help the platform feel more dependable and easier to understand.

Design Approach

I design interfaces to feel easier to understand, navigate, and trust.

My approach is grounded in usability principles that reduce friction, support decision-making, and make digital experiences feel more intuitive from the first screen.

Visibility

Your value proposition, best work, certification, and contact path are all placed where visitors can find them quickly.

Feedback

Buttons, navigation, and page states respond clearly so users always know what can be clicked and where they are.

Mapping

The page moves from introduction to proof to projects to contact in a natural decision-making sequence.

Constraints

Too many choices were removed. The page now keeps attention on the few actions that matter most.

Consistency

Spacing, typography, card structure, and buttons follow one system so the portfolio feels more senior and professional.

How I work

A simple process from messy ideas to clearer screens.

  1. Clarify the main task before styling the interface
  2. Simplify flows so the next step always feels obvious
  3. Keep components, spacing, and patterns consistent
  4. Refine responsive behavior so the design holds up in code
